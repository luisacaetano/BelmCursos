# BelmCursos

Sistema web para venda de cursos online desenvolvido como projeto acadêmico.

## Funcionalidades

- Cadastro e autenticação de usuários
- Catálogo de cursos por linguagem de programação
- Carrinho de compras
- Painel administrativo para gerenciamento de cursos e linguagens
- Sistema de busca

## Tecnologias

- PHP
- MySQL
- HTML/CSS
- JavaScript

## Como Executar

1. Configure um servidor local (XAMPP, WAMP ou similar)
2. Importe o banco de dados `BancoDadosCompleto.sql`
3. Configure a conexão com o banco de dados
4. Acesse via navegador
